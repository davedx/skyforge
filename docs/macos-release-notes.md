Download **Skyforge-macos-arm64.zip** for an Apple Silicon Mac, including Mac Studio. Unzip it and drag **Skyforge.app** into **Applications**. Rust, Cargo, and Xcode are not required.

Requires macOS 11 or later. Install and sign in to Codex or Claude Code separately to use those providers, or configure an OpenAI-compatible server in Settings. Existing Skyforge history and settings remain in your user Library.

This build is ad-hoc signed, without Apple notarization. If macOS blocks it, try opening the app, then go to **System Settings → Privacy & Security → Open Anyway** to approve it.

The standalone **skyforge-macos-arm64** executable is also available. After downloading it, run `chmod +x skyforge-macos-arm64` before launching it from Terminal. **SHA256SUMS** contains SHA-256 checksums for both downloads.
